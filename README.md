# Excel 批量生成带格式 Word 文档工具集

这是一个基于 Python 的办公自动化工具集合。它能够读取同一个 Excel 文件 (`test.xlsx`) 中的不同工作表，并利用对应的 Word 模板（位于 `模板/` 文件夹下）将每一行数据完美匹配并生成带有精美首行缩进、字体原色的 Word 报告文档。目前支持五个分类生成。

## 目录结构
```text
test/
├── test.xlsx                     # [核心数据源] 存放了所有需要生成 Word 的数据总表
├── 模板/                         # [核心模板库]
│   ├── 美食模板.docx
│   ├── 景点模板.docx
│   ├── 购物模板.docx
│   ├── 民宿模板.docx
│   └── 特产模板.docx
├── 生成结果/                     # 根据分类自动创建分类目录并输出对应的所有的 Word 文件
│   ├── 美食/
│   ├── 景点/
│   ├── 购物/
│   ├── 民宿/
│   └── 特产/
├── excel_to_docx_美食.py         # 生成[美食]相关的自动化脚本
├── excel_to_docx_景点.py         # 生成[景点]相关的自动化脚本
├── excel_to_docx_购物.py         # 生成[购物]相关的自动化脚本
├── excel_to_docx_民宿.py         # 生成[民宿]相关的自动化脚本
├── excel_to_docx_特产.py         # 生成[特产]相关的自动化脚本
├── 一键生成全部文档.bat          # 🌟 双击运行：一次性生成所有类别的文档
└── 一键清理生成结果.bat          # 🗑️ 双击运行：一键删除之前生成的所有旧文档
```

## 功能特点
1. **百分百完美保留模板排版**：无论你在 Word 的“`{某字段}`”占位符处设置了什么奇特的特殊字体、段落颜色、还是两字符的首行缩进，脚本都能精准识别并通过底层深拷贝引擎，在拆分写入多行内容时把排版完整无损地带上。
2. **缺省内容智能填补**：无论在 Excel 里它是个空单元格，还是好几排空白的垃圾换行，工具都会把所有的无意义空白清除。如果没有该记录，工具会自动使用 `"无"` 进行占位写入。
3. **强大的“别名”映射功能**：Word 模板里的一些词和 Excel 里的列表头词汇如果对不上（比如：模板需要`{住宿类型}`而表头叫 `房间种类`），内部代码也已经硬编码将那些异名变量全进行了映射，确保没有漏打。
4. **防占用保护**：如果你在使用 Word 查看文件时意外按下了重新生成的指令，程序会跳过已被打开占用的文件并给与报错，防止整个流水线系统崩溃或影响正常文件的生成。

## 使用方法说明

1. 确认系统环境已经安装必需库 `pip install openpyxl python-docx`。
2. 将数据收集表统一整理在 `test.xlsx` 并放在这里。
3. 确保你的模板文件都保存在 `模板/` 文件夹里。
4. **一键生成（强烈推荐）**：直接在文件夹里双击运行 `一键生成全部文档.bat`，它会自动依次执行全部 5 个分类的脚本，完成后停留在界面供你查看生成日志。
5. 你也可以按需在终端里运行指定的单独分类脚本，比如只想更新美食数据：
   ```bash
   py excel_to_docx_美食.py
   ```
6. **一键清理**：下次若是数据大洗牌想要删掉旧文件，可以直接双击运行 `一键清理生成结果.bat`。
7. 生成完毕后，去 `生成结果/` 对应的内部文件夹查看成果即可。
